# futures-live

Clôtures quotidiennes des contrats à terme utilisés par Oléa Terminal (CBOT ZL, ZS, ZM · NYMEX HO · ICE Low Sulphur Gasoil · Bursa FCPO), relevées sur TradingView.

Cette branche ne contient que des données. Elle est mise à jour par `scripts/update-futures.py` selon `scripts/futures-runbook.md` (branche `main`), après contrôle de chaque relevé par somme de contrôle. Le site la lit au chargement.
